# py-portscan

一个用 **Python 标准库**写的多线程 TCP 端口扫描器，零第三方依赖（不需要 pip install 任何东西）。

写它的目的不是"造轮子"，而是把三件事练明白：
1. **TCP 连接的本质**（连上=开放，拒绝/超时=关闭或过滤）
2. **Python 多线程**（`concurrent.futures` 线程池，为什么快、快多少）
3. **安全工具的基本形态**（参数解析、输出报告、法律边界）

## 环境要求

- Python 3.8+（开发环境为 3.13）
- 无第三方依赖，clone 下来就能跑

## 用法

```bash
# 扫描本机常见端口（约 50 个）
python portscan.py 127.0.0.1 -c

# 扫描常见端口并抓取服务横幅
python portscan.py 127.0.0.1 -c -b

# 扫描端口段
python portscan.py 127.0.0.1 -p 1-1024

# 指定离散端口
python portscan.py 127.0.0.1 -p 80,443,3306 -b

# 100 线程 + 自定义超时
python portscan.py 127.0.0.1 -c -t 100 --timeout 0.5
```

## 参数说明

| 参数 | 说明 |
|---|---|
| `target` | 目标 IP 或域名（必填） |
| `-c / --common` | 扫描常见端口表 |
| `-p / --ports` | 自定义端口，支持 `80,443` 或 `1-1024` |
| `-b / --banner` | 抓取服务横幅（SSH/FTP 等会主动报家门） |
| `-t / --threads` | 线程数，默认 50 |
| `--timeout` | 单端口连接超时秒数，默认 1.0 |

## 它是怎么工作的（学习要点）

```
main()
 ├─ 解析参数 → 得到端口列表（常见表 / 自定义解析）
 ├─ socket.gethostbyname() → 域名解析成 IP
 ├─ ThreadPoolExecutor(max_workers=线程数)
 │    └─ 每个端口提交一个任务：scan_port()
 │         └─ socket.create_connection((ip, port), timeout)
 │              ├─ 成功 → 端口开放（可选：抓横幅）
 │              └─ 拒绝/超时 → 端口关闭或被过滤
 └─ as_completed() 收集结果 → 按端口排序输出
```

关键理解：
- **为什么多线程快**：单线程扫 1024 个端口，每个关闭端口都要等满超时；多线程把等待时间重叠起来
- **超时的取舍**：太大 → 慢；太小 → 漏报（慢网络/远端限速时会误判为关闭）
- **横幅的意义**：服务连上后主动发的"自我介绍"，是识别服务版本的第一个信息源
- **进阶方向**（学会了可以自己加）：
  - [ ] UDP 扫描（`socket.SOCK_DGRAM`，原理和 TCP 完全不同）
  - [ ] 输出 JSON / CSV，方便接其他工具
  - [ ] 用 `socket.SO_REUSEADDR` / 半开扫描（SYN scan，需 raw socket，Windows 上受限）

## ⚠️ 法律与伦理

- **只扫描你拥有或获得书面授权的目标**
- 在公网上"随便试试"他人服务器属于未授权扫描，违反《网络安全法》
- 本项目的定位是学习原理 + 打自己的靶场（DVWA/Pikachu 等）

## 已知边界（诚实清单）

- 不做操作系统指纹识别（那是 Nmap 的领域）
- 不做服务版本自动识别，横幅只原样展示
- 防火墙丢弃（DROP）的端口会表现为超时，无法与"不存在的主机"区分——这是 TCP 全连接扫描的固有局限
