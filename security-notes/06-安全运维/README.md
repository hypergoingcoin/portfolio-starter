# 06-安全运维

安全运营（SecOps）方向的知识沉淀——你的**第二技能线**。

## 计划覆盖

- [ ] WAF / IDS / IPS 的区别与协作（为什么有 WAF 还会被打穿）
- [ ] 日志分析：系统日志、Web 访问日志、数据库日志能看出什么
- [ ] 应急响应流程：从告警到止血的标准动作
- [ ] webshell 排查：文件、进程、网络连接三个维度怎么查
- [ ] 堡垒机 / SOC 是干什么的（建立体系认知即可）

## 与渗透线的互补写法

> 每学一个攻击手法，在运维侧记一条对应的检测/防御点。
> 例如：学了文件上传 → 记"WAF 该怎么配上传规则、运维侧如何发现 webshell"。
> **攻防复合**是你简历上区别于纯脚本小子的核心差异点。
