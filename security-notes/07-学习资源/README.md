# 07-学习资源

好书、好站、课程清单（附一句话点评，只收自己真看过/用过的）。

## 入门期推荐（起步用这些就够了，别囤）

| 资源 | 类型 | 一句话点评 |
|---|---|---|
| 《图解HTTP》 | 书 | 薄、图多，HTTP 入门最快的一本 |
| 《鸟哥的Linux私房菜》 | 书 | Linux 命令与管理的百科全书，当手册查 |
| 浙江大学 计算机网络 网课（中国大学MOOC） | 网课 | 体系最完整的中文计算机网络课 |
| DVWA 官方各模块源码 | 靶场 | 最好的 PHP 安全教材：漏洞代码和修复代码都在眼前 |
| PortSwigger Web Security Academy | 在线实验室 | 免费、体系化，Burp 官方出品，进阶主力 |
| BugKu / 攻防世界 / CTFhub | CTF 平台 | 刷题保持手感，从 Web 方向开始 |
