# 02-Web安全

SQL 注入、XSS、文件上传、命令执行等 Web 漏洞的**原理笔记**放这里。

> 与 `04-靶场Writeup` 的分工：这里放"这类漏洞是什么、为什么、怎么防"的通用原理；靶场里逐关复现的过程放 04。

## 计划覆盖

- [ ] SQL 注入：原理、联合查询、报错/时间盲注、宽字节
- [ ] XSS：反射型/存储型/DOM 型、Cookie 窃取、HttpOnly 的作用
- [ ] 文件上传：后缀绕过、MIME 校验、二次渲染、.htaccess/.user.ini
- [ ] 文件包含：LFI/RFI、伪协议（php://filter、data://）
- [ ] 命令执行与代码执行
- [ ] CSRF、SSRF、越权（入门后）

## 每篇必须回答的三个问题

1. 漏洞的**根因**是什么（缺哪个检查/信任了什么）
2. 利用的**前提条件**是什么
3. 正确的**防御**写法是什么（参数化查询、输出编码、白名单……）
